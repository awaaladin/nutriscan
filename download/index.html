NutriScan

Scan any packaged food's barcode for an instant WHO-based health score and diabetic risk read.

Download for Android
v0.2.0 · Beta build · Android 8.0+

After downloading

  1. Open the downloaded file from your notifications or Downloads folder.
  2. If Chrome warns about unknown apps, tap Settings → allow Chrome to install unknown apps → go back and tap Install.
  3. Open NutriScan and create an account to start scanning.
This is a beta build shared directly for testing, ahead of the Play Store release. Educational health information only — not medical advice.
