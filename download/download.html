Before you download

Four things worth knowing

  • It is a beta. Expect rough edges. Features and data coverage are still growing.
  • It is information, not advice. Scores are educational. For medicines and health conditions, ask a doctor or pharmacist.
  • It cannot prove a pack is genuine. It shows evidence. You decide.
  • You are in control of your data. Health details are optional and you can delete your history. Privacy Policy
Install

Install in five steps

1

Download the file

Open this page in Chrome on your Android phone, tick the box and tap Download.

2

Open it

Tap the notification when it finishes, or find nutriscan.apk in your Downloads folder.

3

Allow the install

Android will say the app is from an unknown source, because it is not from the Play Store. Tap Settings, allow Chrome to install apps, then go back.

4

Tap Install

If Play Protect asks, choose to install anyway. You can turn the permission off again afterwards.

5

Open NutriScan

Create an account, optionally add your health details, and scan something from your kitchen.

Check it is genuine

Verify the file

Only download NutriScan from this page. To be sure your file is exactly the one we published, compare its SHA-256 fingerprint with ours.

Windows (PowerShell)

Get-FileHash .\nutriscan.apk -Algorithm SHA256

Mac or Linux

sha256sum nutriscan.apk

If the two do not match, do not install it, and tell us.

Help

Install questions

Is it safe to install from outside the Play Store?

It is as safe as the source. Only install from this page, and verify the fingerprint above. A Play Store release is planned.

Which phones work?

Android 8.0 or newer. There is no iPhone version yet.

It says “app not installed”

Remove any older NutriScan build first, make sure you have a few hundred MB of free space, and try again.

How do I update?

Download the newest file from this page and install it over the old one. Your account and data stay.
